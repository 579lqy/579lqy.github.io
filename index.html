模型生命周期 · PRD V1

模型下架

把模型下架收敛为可审计、可回放、可追责的六阶段流程，兼顾存量权益保护与合规风险。

  • 状态机 ONLINE / SOON_OFFLINE / OFFLINE（不可恢复）
  • 以（企业,模型）去重，避免重复通知与重复发券
  • 单模型包 / 组合包 L0·L1 权益补偿，非退款形式
  • 正式下架后 API 统一返回 410 MODEL_RETIRED

计费 / 发票 · PRD V2

发票开具

个人 / 企业双空间开票，解决逐条勾选成本高、多账户开票割裂、金额不透明等痛点。

  • 按订单 / 按月周期开票，多订单可合并一张
  • 企业合并 / 拆分开票，按账户核算
  • 状态判定引擎：订单级 5 值 + 账单级 3 值，零手填
  • 可开票金额 = 总计 − 历史已开 − 本月不可开，精度到分

计费 / 账单 · PRD V1

账单优化（月账单概览）

把分散在多产品 / 多账号的消费，做成可归因、可下钻、可对账的月账单概览。

  • 近 12 月查询窗口，汇总卡三金额 + 总状态机
  • 消费明细按产品，账本（体验金 / 现金）展开
  • 出账流水 / 还款明细下钻，PDF + CSV 导出
  • 四组金额勾稽误差 = 0
