发票开具功能 · 概要设计

> 基于原型 发票需求优化V2.html ，字段名/函数名与原型代码保持一致。

1. 功能描述

1.1 功能定位

用户（ToC 个人 / ToB 企业管理员）在同一入口下，选择一批可开票的消费记录，一次提交生成发票申请。核心解决两个问题：
- 按量付费一个月产生几十条账单，不能逐条勾选 → 提供"按月周期"汇总开票
- 企业下有主账户和子账户，管理员需要跨账户统一开票，还要能拆分 → 提供"账户范围 + 合并/拆分"

1.2 功能清单

模块 子功能 适用空间
空间切换 个人空间 / 企业空间 tab 切换 全部
账户范围选择 搜索、全选/清空、多选账户 仅企业空间
发票拆分模式 合并为一张 / 按账户分别开票 仅企业空间
开票方式切换 按订单开票 / 按月周期开票 全部
周期选择器 当前月锁定、近3月快捷、更早月份下拉 仅"按周期"模式
周期汇总 可开票金额、订单数/可开票笔数、查看计算明细 仅"按周期"模式
计算明细弹窗 公式三项拆解 + 说明气泡 + 下钻 + 按账户拆分明细 全部（按账户拆分仅企业）
订单筛选与列表 关键字/状态/日期区间筛选，批量全选/清空 全部
订单详情页 账单级明细分页展示 全部

底部汇总与提交 已选账户数/订单数/金额，提交开票申请 全部

1.3 功能边界

不包含：已开具列表、发票信息（抬头）管理、真实开票网关对接、发票文件生成、发票冲红。

3. 处理流程

3.1 页面初始化流程

加载页面
 → 初始化账户列表（企业：默认全选全部账户）
 → 初始化周期选择器（计算近3月 chip + 4~12月下拉，默认选中最近已完结月）
 → 计算当前范围（空间 × 账户范围）内的订单可开票金额、状态
 → 渲染周期汇总 / 订单列表（默认全选 invoiceable>0 的订单）
 → 渲染底部汇总栏

3.2 订单状态计算流程（核心处理逻辑）

输入：订单 { amount, invoicedAmt, excludedAmt, recurring, period }
Step1: invoiceable = MAX(0, amount − invoicedAmt − excludedAmt)
Step2: 判定状态
  IF recurring=true AND period=当前自然月 → status=pending（未出账，锁定不可选）
  ELSE IF invoiceable=amount → status=ok
  ELSE IF invoiceable>0 → status=partial
  ELSE IF invoicedAmt>0 → status=invoiced
  ELSE → status=no
Step3: 渲染对应标签与复选框可用性（invoiceable=0 时复选框禁用）

3.3 筛选与选择联动流程

用户操作（切空间 / 切模式 / 切周期 / 变更账户范围）
 → 清空 selected（已选订单集合归零，避免跨维度脏数据）
 → 重新计算当前范围内订单
 → 重新渲染列表（invoiceable>0 的订单默认自动勾选）
 → 重新渲染底部汇总栏

用户操作（筛选表单查询）
 → 在当前范围订单基础上按 关键字/状态/日期 过滤
 → 更新 lastList（供"全选筛选结果/清空本次选择"使用）
 → 渲染结果提示文案 + 列表

3.4 提交开票流程

用户点击"申请开票" / "提交拆分开票申请"
 → 汇总 selected 中的订单：已选订单数、已选金额、涉及账户数
 → IF 企业+合并模式 AND 已选金额>核定限额 → 已在页面持续展示警示，不阻断提交
 → IF 企业+拆分模式 → 按账户分组，逐账户生成一张发票申请
 → 提交（原型为 mock alert，实际应调用开票申请接口）
 → 成功后应清空已选、提示结果（原型未实现，需在详设阶段补齐）

3.5 计算明细弹窗数据流程

点击"查看计算明细"
 → 取当前范围（空间×账户×周期）内全部订单
 → 汇总：总额 / 已开票 / 不可开票 / 可开票 四个数字
 → [企业] 按已选账户分别求和可开票金额，过滤掉为0的账户
 → 渲染弹窗

4. 交互描述

# 交互点 触发方式 反馈
1 空间切换 点击顶部 tab 立即切换页面标题、显示/隐藏企业专属卡片，已选订单清空
2 拆分模式切换 点击"合并/按账户"文字 单选态切换（radio 高亮），底部提交按钮文案联动
3 账户下拉展开/收起 点击触发器 / 点击页面空白处 展开显示搜索框+列表；点击外部区域自动收起
4 账户搜索 输入框实时输入 列表实时过滤（无节流/防抖，原型为同步过滤）
5 账户勾选 点击整行 复选框切换态，触发器文案更新（"XX等N个账户" 规则见2.2）
6 账户全选/清空 点击"全选"/"清空"按钮 批量勾选或取消全部账户
7 开票方式切换 点击卡片 卡片高亮态切换，下方筛选表单和列表列结构联动切换
8 周期 chip 点击 点击 chip / 下拉选择"更早月份" 高亮切换到目标周期，已选订单清空，列表和汇总重新渲染
9 当前月 chip 不可点击（disabled 样式） 无响应，仅作说明用途
10 查看计算明细 点击文字链接 打开居中弹窗，点击遮罩层或"关闭"按钮/×关闭
11 说明气泡（?图标） 点击 展开黑底提示条，同一时刻仅一个气泡展开，再点其他?自动收起当前
12 查看明细（历史已开票/不可开票） 点击文字链接 关闭弹窗，跳转到下钻明细页（非新开弹窗，是页面替换）
13 按账户拆分明细 点击折叠标题 展开/收起子列表，箭头图标随之翻转
14 筛选查询/重置 点击按钮 查询：按当前表单条件重新过滤列表；重置：表单恢复默认值并重新查询
15 全选筛选结果 点击 对当前筛选结果中 invoiceable>0 的订单全部勾选（不影响列表外的其他订单选择态）
16 清空本次选择 点击 仅清空当前筛选结果范围内的已选订单
17 订单行复选框 点击 invoiceable>0 时可切换选中态；=0 时禁用态，点击无响应
18 订单"详情" 点击 页面整体替换为订单详情页（非弹窗），返回按钮回到列表并保留原选择态
19 详情页分页 点击上一页/下一页 页码±1并重渲染表格；首页禁用"上一页"，末页禁用"下一页"
20 提交开票 点击底部按钮 触发提交流程（原型为 alert 提示，正式版需替换为真实提交+loading+结果反馈）
21 超限警示 已选金额超限时自动出现，无需用户操作 橙色提示条，不阻断提交按钮可点性
